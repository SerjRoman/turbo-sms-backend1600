# Websockets - 02.05.2026

## Концепт

Мы создаем сервер на основе HTTP, поверх которого мы налаживаем вебсокеты.

## Установка

Для начала, понадобится установить 2 библиотеки:

1. **socket.io** - Для работы с вебсокетами.
2. **http** - Для работы с HTTP запросами.

## Использование

#### HTTP:

Начало:

- Создаём сервер express: он нам понадобится для прослушивания всех запросов от клиента, КРОМЕ real-time запросов. _Аналогия: Мозг для обработки HTTP_
- Создаём **httpServer** c помощью функции **createServer** из **http**, который будет работать как обертка для express.

Запуск:\
express сервер **не запускаем**! Для него можем только сделать обработку запросов, но без listen.
Запускаем сервер от **http** с очень похожей конструкцией.\

Пример:

```js
httpServer.listen(PORT, HOST, () => {
  console.log(`
            HTTP Server is running on: http://${HOST}:${PORT}
        `);
});
```

### Websockets:

#### Начало:\

Для работы с вебсокетами, создадим объект от **SocketIOServer** из **socket.io** _(изначально называется Server, но для удобства рекомендуется переименовать)_\

#### Работа с ним:\

У сервера вебсокетов есть функция **on** - она позволяет добавить функцию на событие которое произойдет.\
Оно может обрабатывать событие _"connection"_, которое выполнит следующе указанную callback функцию при подключении клиента к серверу по вебсокету.\
В сallback функцию передается аргумент socket:

- socket — это объект, представляющий уникальное соединение с одним клиентом.
- Через него мы будем общаться (отправлять и получать события) именно с этим клиентом.
  _Copyright by Кикот Сергей_
  Сокет также может обрабатывать события, которые могут иметь разные имена (указывается клиентом), из резервированных можно отметить:
- **disconnect** - Происходит когда клиент отключается от вебсокета
- **connect** - Происходит при подключении клиента

**Отправка ответа пользователю**\
Для отправки ответа пользователю, у сокета (и у сервера вебсокетов) имеется функция **emit**. Он работает следующим образом:

- При использовании с сервера, оно отправляет сообщение **всем** подключенным к этому серверу вебсокетов _(broadcast)_
- Первым аргументом указываем **имя события** _(строку!)_, которое присылаем пользователю _(Также как пользователь присылает серверу)_
- Следующими аргументами мы указываем данные, что мы шлем пользователю. Отправлять можно что угодно: Объекты, строки, числа и т.д.
